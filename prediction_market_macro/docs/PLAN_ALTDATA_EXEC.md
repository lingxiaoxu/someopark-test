## §26 P0 —— 执行层与数据卫生(不碰模型,先止血)

浮亏归因(49 条在仓腿,与总额 −$10.115 逐分对齐):

```
入场滑点 (+1¢/腿)   −$3.250   ← §26.1
手续费              −$1.550   ← 名义本金 2.7%
宽价差 mid 幻象     −$3.415   ← §26.2
真实价格不利变动    −$1.900   ← 只有这份归模型(§27)
```

### §26.1 滑点施加在下单量之后(`ops/ledger.py:35`、`ops/decide_all.py:92`)

`count = int(usd / st.cost)` 用**滑点前**价定量,`px = min(leg.price + PAPER_SLIP, 0.99)` 再加 1¢。
penny 腿上 1¢ = 100% 滑点:ask=$0.01 → count=100 → 实付 $2.00,是 $1 上限的 2 倍。

实测 **19/99 个仓位真实亏顶破 $1**,破限倍数恰好 =`(ask+0.01)/ask`:

| id | 系列 | ask | count | 真实亏顶 |
|---|---|---|---|---|
| 743 | KXAAAGASW | 0.01 | 100 | **$2.14** |
| 5/7/8 | KXFEDDECISION | 0.03 | 33 | $1.41 |
| 38 | KXPCECORE | 0.04 | 25 | $1.34 |

改法:**先算含滑点成交价,再用它定 count**;并对便宜腿改比例滑点(1 个 tick 对 1¢ 腿不是合理假设)。
顺带补 PLAN §22-26 一直没做的 `size ≤ 20% depth` 比例门。

> 注:一度怀疑总敞口 $247 vs 记账 $99(2.5×)。查证 `strategy/edge.py:98 max_loss=eff` 对 bucket **是正确的**
> ——bucket 任何结果都至少回 $1,所以那是现金占用不是风险敞口。真实亏顶合计 $23.6。**此项非 bug。**

### §26.2 `_mid` 在宽价差上取中点(`ops/pnl.py:112`)

49 条腿里 **14 条价差 ≥15¢**,最宽 KXCPIYOY-26SEP-T3.4 是 **0.18/0.98(80¢)**。
中点把 0.99 买入的「core CPI ≥ 0.0」这种近乎必然的腿砍到 0.825。这不是亏损,是拿单边挂单簿中点当市价。
改法:价差 ≥ 阈值时标到持仓的不利端(保守)或不标;并确认 `ops/exits.py` 不会被幻象误触止损。

### §26.3 手续费占名义 2.7%

`taker_fee = 0.07·C·P(1−P)` 是对的,但 penny 腿上 fee/notional 高达 7%。
接 PLAN §22-44 一直挂着的 **maker-first 入场**(计划自己估「省 30–50% 费用」),与 §26.1 是同一处代码。

### §26.4 `strategy/decision.py:142` 的 `max(st.cost, 0.01)` 兜底

与 §26.1 同源,一并处理。

### §26.5 `candles` 46% 脏行

6700/14683 行 `end_ts=0`。`research/backtest.py::_market_leg_prob` 用 `end_ts<=asof ORDER BY end_ts DESC`,
脏行永远满足条件 —— 当某腿只有脏行时会返回**时间戳为 1970 年的价格**当作历史市价。
定位写入方(`ingest/kalshi_md.py`)、修复、清理。**这直接影响 §29 重跑出的所有 Brier。**

## §27 P0 —— 模型修复(唯一真赔钱的那部分)

### §27.1 Fed 长期限 H0 塌陷(`model/fed.py`)

存档决策 `#7`(2027-03):`H0=0.013724` —— 模型认为 20 个月后 FOMC 有 **98.6% 概率不维持**。
按同一 asof 重跑全部未来会期:

```
2026-12  H0=0.501      2027-03  H0=0.170  ← 塌陷
2027-01  H0=0.572      2027-04  H0=0.906  ← 相邻期限差 5 倍,完全不平滑
2027-06 起 H0=0.5969 逐位相同 —— 超过某期限后模型躺平
```

H0 一塌,概率被挤到 C26/H26 这类「一次跳 50bp」的腿,而市场只报 1–3¢
→ 模型在最便宜最不可能的腿上机械制造最大 edge(#7 `net_edge=0.325`)。
四笔最大浮亏里两笔 + 此前 3 笔止损全是这类。

改法:(a) H0 概率下限 + 期限单调性约束;(b) **用 §25.1 已入库的 ZQ 曲线锚定路径**
(ZQN26…ZQH27 覆盖到 2027-03,正好覆盖出事的那个期限);(c) 引入 DGS2/T5YIE。
市场隐含路径一旦接上,就不需要模型自己外推出 H0=1.4% 这种数。

### §27.2 能源分布用正态 σ(`model/energy.py`)

KXAAAGASW 是 14 个 series 里 Brier 最差:**0.14235 vs 市场 0.01709(差 8 倍)**。
`#743` 的分布 `gmix[[1.0, 4.129125, 0.08562]]`,把 4.20 算成 20%(市场 1%)。

实测 GASREGW 周变化:全史 sd=0.0525、近5年 sd=0.0819、**中位数绝对值只有 0.0190**、p90=0.0770。
即分布**肥尾**,用 sd 拟合正态会把典型周放大约 3 倍。用中位数隐含 σ 重算 4.20 只有 0.6%,与市场的 1% 一致。

> 自我更正:最初怀疑「σ 太宽」。实测 sd 口径下 0.0856 并不离谱 —— **问题是分布形状不是尺度**。

改法:经验分位数 / t 分布替代正态;接入 §25.1 里**已入库却无人消费的 `GASOLINE_STOCKS_WEEKLY`**(1908 行,1990 起)。

### §27.3 CPICORE 网格点质量堆积(`model/cpi.py`)

`#649` 分布均值 0.10028 正落在 0.1 网格点上,`grid_pmf` 把 ~55% 质量堆在单一 bucket。
该笔的 −$0.73 **全部是 §26.2 的盯市幻象,不是这个问题造成的** —— 但均值贴格点时的质量分配仍需复核。
优先级低于 §27.1/§27.2。

### §27.4 `AAA_DAILY` 违反 §5-bis 口5

energy v0.4+ 在生产消费一个只有 4 行、历史不可回溯的源。
两条路:(a) 按自己的铁律把它移出上线前回测路径,只做 live-forward shadow;
(b) 承认它是 live-only 特征并在模型卡显式标注。**选 (a)**,与 §7-bis 采纳协议一致。
